EntrePáginas - PARTE WEB E SERVIDOR JAVA

As 3 pastas (entrepaginas-bancodedados, entrepaginas-java, entrepaginas-web) devem ficar
lado a lado, dentro da mesma pasta.

BANCO DE DADOS
  O sistema usa o banco do servidor do professor. As tabelas têm o sufixo _grupo1
  (ex.: usuario_grupo1, livro_grupo1) e o código Java já usa esses nomes.
  Para testar no PC sem acesso ao servidor do professor, rode no MySQL Workbench o script
  entrepaginas-bancodedados\entrepaginas_grupo1_local.sql (cria o schema "entrepaginas" com
  as mesmas tabelas e dados de exemplo). NÃO rode esse script no servidor do professor.

REQUISITOS
  - JDK 21 ou superior instalado.
  - Acesso ao MySQL (servidor do professor ou MySQL local).

COMO RODAR
  1. Em entrepaginas-java\db.properties já estão o endereço (pontelli.net.br), o schema e o usuário
     do servidor do professor. Falta só colocar a senha do slide da aula na linha password=.
     (Alternativa: variáveis de ambiente DB_URL, DB_USER e DB_PASSWORD.)
     Nunca envie o db.properties com a senha preenchida.
  2. Abrir a pasta entrepaginas-java no IntelliJ ou no VS Code (o Maven baixa as dependências).
  3. Abrir src\main\java\servidor\ServidorWeb.java e rodar a classe.
  4. No navegador: http://localhost:8080

HOSPEDAR O SITE NO NETLIFY
  O Netlify só hospeda páginas estáticas (HTML, CSS e JS): ele NÃO executa o servidor Java.
  Então são duas partes:
    - Site (pasta entrepaginas-web): vai para o Netlify.
    - Servidor Java (ServidorWeb): precisa rodar em algum lugar com endereço público https.
  Depois que o servidor Java estiver no ar, coloque o endereço dele em
  entrepaginas-web\js\config.js (constante API_URL) e publique a pasta entrepaginas-web.
  O servidor Java também precisa conseguir acessar o banco do professor.
  A porta pode ser definida pela variável de ambiente PORT (padrão 8080).
